# Placement Readiness Tracker

## Project Purpose
This project is a Python command-line application
that tracks student practice test scores.

## Features
- Stores student records.
- Calculates student averages.
- Assigns grades.
- Identifies students needing practice.
- Finds the top scorer.
- Solves the runner-up score problem.

## Technologies Used
- Python
- Git
- GitHub
- VS Code

## How to Run

Run the student tracker:

python main.py

Run the runner-up program:

python runner_up.py
